### Проект SLA-документа для Техническая поддержка пользователей TrueConf

1. **Стороны и предмет соглашения**

Поставщик услуги: ООО «Труконф», именуемое в дальнейшем "Исполнитель", в лице [ФИО] действующего на основании [номер доверенности], предоставляющие услуги технической поддержки сервиса видеоконференцсвязи на базе TrueConf Server.

Заказчик услуги: [Наименование организации], именуемое в дальнейшем "Заказчик", использующих сервис видеоконференцсвязи для обеспечения производственной деятельности.

Настоящий документ регулирует требования к качеству и объему услуг по сопровождению программного обеспечения видеоконференцсвязи TrueConf Server, установленного в инфраструктуре Заказчика, порядок взаимодействия сторон при возникновении инцидентов и запросов на обслуживание, а также сроках их устранения.  


2. **Сущность услуги**

2.1. Границы сервиса

Услуга охватывает серверную часть TrueConf Server (далее Продукт) и связанные с ним компоненты и устройства, приобретенные и установленные в инфраструктуре Заказчика.

2.1.1. При развертывании на операционные системы семейства Windows Server под серверной частью TrueConf Server понимается:

* TrueConf Server — основная служба
* TrueConf Database — служба сервера базы данных
* TrueConf Web Manager — отвечает за работу панели управления TrueConf Server, гостевой страницы, личного кабинета, планировщика, веб-приложения (подключение к конференции через браузер по WebRTC), также отвечает и за настройки HTTPS.
* TrueConf Server Manager — менеджер работы с реестром Windows и файлами настроек. 
* TrueConf Bridge — служба, которая получает web socket-сообщения (команды) от веб-приложений и преобразовывает их в понятные для TrueConf Server транспортные сообщения.

2.1.2. При развертывании на операционные системы семейства Linux под серверной частью TrueConf Server понимается:

* trueconf — основная служба, движок сервера.
* trueconf-db — служба базы данных.
* trueconf-web — отвечает за работу панели управления TrueConf Server, гостевой страницы, личного кабинета, планировщика, веб-приложения (WebRTC) и за настройки HTTPS. 
* trueconf-manager — менеджер работы с БД и файлами настроек.
* trueconf-php — служба отвечает за обработку определенных скриптов, является внутренней системной службой.
* trueconf-bridge — служба, которая получает web socket-сообщения (команды) от веб-приложений и преобразовывает их в понятные для TrueConf Server транспортные сообщения.

2.1.3. Прочее программное обеспечение и оборудование так же попадающее под дейстие документа:
* TrueConf AI Server;
* TrueConf monitor;
* TrueConf Room;
* TrueConf Kiosk;
* TrueConf Videobar;
* Клиентские приложения TrueConf для Windows, Linux, macOS, Android; iOS.
